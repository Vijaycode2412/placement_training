# Personal Resume Website

A simple resume website created using basic HTML and CSS. This project displays my personal information, education, skills, projects, experience, and certifications in a professional resume format.

## Features

- Clean and simple resume layout
- Contact information with clickable links
- Skills displayed in a table format
- Education section
- Experience section
- Projects section
- Certifications and achievements
- Responsive and easy to customize

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
Resume/
│
├── index.html
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in any web browser.
3. The resume will be displayed.
